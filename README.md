App Description:I want to build an app for data and stats tracking for sports, similar to StatMuse. The app will be a single source for Users to find and query historical(hopefully) and current player and team statistics.

Must-Do Requirements : 
I should have two users: an Admin and a normal User (or Visitor).

The Admin must be able to add, update, and manage the core data. This includes adding new Sports (e.g., NBA), Teams (e.g., Lakers), and Players (e.g., LeBron James). The Admin will also be responsible for uploading or entering the stats for each player after a game or season.

The User must be able to search the database. They should be able to see a list of sports, teams, and players. They must be able to select a player and view their career stats, or filter stats by a specific season. He can also deliver feedback through a form.

Would love to do:
 Allow the User to use a natural language search bar (e.g., "who had the most points in 2023?").
 Allow the User to compare two players' stats head-to-head.
 The app will display some data using charts or graphs.
 The app will support multiple sports NBA, NFL, MLB etc..(hopefully)
 The User can create an account to save favorite players or searches.
